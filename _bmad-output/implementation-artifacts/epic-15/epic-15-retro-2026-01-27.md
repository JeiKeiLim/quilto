## What Went Well

### 1. Architecture Decision Delivered
The critical architecture issue from Epic 13 ("Quilto provides agents but no orchestration") was fully resolved. Quilto now has:
- Single entry point: `session.process()`
- LangGraph state machine with declarative edges
- Observer auto-invocation on all flows
- Session-based conversation support

### 2. Critical Bug Fix (Story 15.5)
`PlannerInput` validation was failing silently because `retrieval_history` was passed as `None` instead of `[]`. This caused:
- Plan node to throw ValidationError
- Exception caught silently (lines 805-807)
- Observer never reached

Fix: Default `retrieval_history` to `[]` in orchestration.py.

### 3. Code Review Quality
Reviews caught real issues before production:
- H1: Mutable default lists (fixed with `Field(default_factory=list)`)
- H2: Protocol `isinstance()` needs `@runtime_checkable`
- Silent exception handling hiding bugs

### 4. Test Coverage
Over 100 new tests added:
- 27 model validation tests
- 41 session management tests
- 28 orchestration tests
- 10 Observer integration tests

## Challenges and Issues Discovered

### 1. Incomplete Migration (Story 15.4)
Story 15.4 only migrated QUERY flow to Quilto. Swealog CLI still:
- Imports `RouterAgent`, `ParserAgent` directly
- Calls Router BEFORE Quilto (runs twice)
- Bypasses Quilto for LOG and CORRECTION flows

**Files with direct agent imports:**
- `auto_cmd.py` - RouterAgent
- `log_cmd.py` - RouterAgent
- `flows.py` - ParserAgent
- `input.py` - RouterAgent, ParserAgent
- `import_cmd.py` - RouterAgent, ParserAgent

### 2. Response Generation Broken
Feedback records show: `"I encountered an error generating a response."`
Synthesizer failing silently. Root cause needs investigation (Story 16.2).

### 4. Lost Observability
`ProgressHandler.on_agent_complete()` only receives `(agent, elapsed)`, missing the actual output. Feedback recording lost all intermediate data.

## Key Learnings

1. **Half-migrations are worse than no migration.** Story 15.4 created two code paths - one through Quilto, one bypassing it. This caused confusion and bugs.

2. **Silent exception handling hides critical bugs.** The `retrieval_history=None` bug in 15.5 was hidden for the entire orchestration development. Always log caught exceptions.

3. **Reference implementations matter.** Swealog should demonstrate ideal Quilto usage. A messy reference app undermines the framework.

4. **Incremental patches vs clean rewrite.** When architecture is fundamentally wrong, patching prolongs pain. Epic 16 restructuring chose rewrite over patches.
