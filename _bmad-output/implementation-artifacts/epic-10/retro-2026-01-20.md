## What We Struggled With

### 1. Story 10.5 Fix Not Working in Practice

**Issue:** Despite unit tests passing, real usage shows retriever still tries term search before date-range for temporal queries.

**Root Cause Analysis:**
- Unit tests mock LLM responses, can't verify actual Planner behavior
- Prompt guidance may not be strong enough for real LLM inference
- Gap between test environment and production behavior

**Action:** New story 11-3 to investigate and fix properly

### 2. Gap Between Unit Tests and Real LLM Behavior

Mocked tests verify:
- Prompt contains expected text
- Code paths execute correctly
- Schemas validate

But cannot verify:
- LLM actually follows prompt guidance
- Real-world query handling
- End-to-end quality

### 3. File Complexity Growth

`pairwise_judge.py` reached 565 lines - approaching refactoring threshold.

## Significant Discoveries

### Discovery 1: Retrieval Priority Bug

**Finding:** Story 10.5's retrieval strategy priority fix is not working in real usage. Term search is still attempted before date-range for temporal queries.

**Impact:** Query quality suffers for temporal queries ("last week", "yesterday", etc.)

**Resolution:** Added as Story 11-3 for proper investigation with real LLM testing.

### Discovery 2: Dogfooding Feedback Loop Proposal

**Proposed by:** Jongkuk Lim

**Workflow:**
```
1. User runs: swealog auto "..."
2. Quilto generates response
3. Swealog prompts: "How was this response?"
4. User provides natural language feedback
5. System records: query + intermediate outputs + response + feedback
6. Collect dataset for improvements
7. Analyze dataset with Mary → Generate improvement stories
8. Implement fixes
9. Archive dataset, start new iteration
```

**Benefits:**
- Real-world usage data (not synthetic)
- Human quality judgments attached
- Intermediate outputs show exactly where issues occur
- Closes the loop on quality improvement

**Storage Structure:**
```
tests/eval/feedback/
├── active/                    # Current collection
├── archive/
│   ├── iter-001/             # Completed iterations
│   │   ├── records/
│   │   ├── analysis.md
│   │   └── stories-generated.md
│   └── iter-002/
└── README.md
```
